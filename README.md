# i2b2t 4 Anarchy
An Plugin For Anarchy Minecraft Server
- I2B2T Anarchy Server IP:
- IP: i2b2t.jo3.org
- Port: 46265
- Both Java And Bedrock
- Website: [I2B2T Official Website](https://i2b2t.fwh.is/?i=1)
# Feature
- Joke Commands:
- /dupe, And /seed
- Actual Command:
- /joindate, /playtime, /lastseen, And /vote
#  Building from source

First, <u>clone</u> this repository.

Then run the following command in the root directory:

```
./gradlew clean build
```
